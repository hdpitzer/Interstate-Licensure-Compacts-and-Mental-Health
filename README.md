# Interstate-Licensure-Compacts-and-Mental-Health

This project examines the impact of interstate licensure compacts on population mental health.

## Data
- Interstate licensure compact participation comes from the Interstate Medical Licensure Compact and the Psychology Interjurisdictional Compact 
- Self-reported mental health comes from BRFSS
- Suicide rate per 100,000 comes from CDC Wonder
- SSRI prescribing comes from the Medicare Part D Prescribers Files
- Provider licensure status comes from NPPES
